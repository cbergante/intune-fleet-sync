# Security

Do not post credentials, tokens, real client details, or device CSV reports in issues. Reports contain tenant and device metadata and should be protected locally.

Before publishing, enable GitHub private vulnerability reporting under repository Settings > Security where available. Once enabled, use the Security tab's private reporting feature for sensitive vulnerabilities. If unavailable, do not disclose sensitive details in a public issue; ask the maintainer to establish a private reporting route.

Never store authentication secrets in this repository. This starter uses interactive delegated authentication and has no embedded credentials.
